## 1. Cardsorting de contenidos

Antes de dibujar cualquier pantalla, listamos todo el contenido que el sitio necesitaba y lo agrupamos en 3 categorías, que se convirtieron en las 3 páginas del sitio:

- **Inicio** → gancho principal, riesgos, servicios, prueba social, llamado a la acción.
- **Acerca de** → misión, visión, historia, equipo, proceso de diseño.
- **Contacto** → formulario, datos de contacto, enlaces externos.

## 2. Wireframe de baja fidelidad (texto)

### Inicio
```
[ Header: logo | Inicio Acerca Contacto | CTA ]
[ Hero: titular + texto + botones  |  panel "actividad en vivo" ]
[ Franja de estadísticas de riesgo (3 columnas) ]
[ Grid de 6 servicios (3x2) ]
[ Bloque de video ]
[ Franja de métricas de la empresa ]
[ Callout / CTA final ]
[ Footer: about + sitio + servicios + enlaces externos + redes ]
```

### Acerca de
```
[ Header ]
[ Hero de página: titular + texto ]
[ Misión / Visión (2 columnas) ]
[ Historia (texto + cifra destacada) ]
[ Equipo (3 tarjetas) ]
[ Proceso de diseño (lista numerada de pasos) ]
[ Bloque de audio ]
[ Footer ]
```

### Contacto
```
[ Header ]
[ Hero de página ]
[ Columna izquierda: datos de contacto + enlaces externos + redes ]
[ Columna derecha: formulario (6 campos) ]
[ Tabla de solicitudes guardadas + botón exportar ]
[ Footer ]
```

## 3. Justificación de la técnica

Se usó wireframe de baja fidelidad + cardsorting** en lugar de mockup visual porque el objetivo en esta etapa era validar la estructura y jerarquía de la información de las 3 páginas antes de invertir tiempo en el sistema visual, que se definió después como un paso independiente.
